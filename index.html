실시간 공유 연결 설정
시연에 참여하는 모든 기기에서 같은 Firebase 프로젝트 설정을 사용해.
Firebase 연결 전
초기 설정 순서
1) Firebase 프로젝트 생성 → 웹 앱 추가 → 설정 객체 복사
2) Realtime Database 생성, Authentication에서 이메일/비밀번호 로그인 사용 설정
3) Authentication에서 관리자 이메일 계정 생성 후 UID를 위에 입력
4) 아래 보안 규칙을 Realtime Database 규칙에 적용한 뒤 모든 접속 기기에서 Firebase 연결
Firebase 웹 설정값은 브라우저에 공개되는 값이야. 데이터 쓰기 권한은 반드시 아래 보안 규칙으로 제한해야 해. 관리자 UID를 비워 두면 관리자 로그인이 활성화되지 않아.
